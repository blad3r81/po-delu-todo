# Сообщение для отправки

Здравствуйте! Выполнил тестовое задание — сайт со списком задач «По делу».

Можно добавлять задачи, отмечать выполненные и удалять записи. После обновления страницы список и отметки сохраняются. Дополнительно сделал фильтры, отмену удаления и адаптацию для телефона.

Сайт: https://po-delu-todo.vercel.app/

Код: https://github.com/blad3r81/po-delu-todo

Использовал Codex от OpenAI для разработки и проверки. Проект написан на HTML, CSS и JavaScript, данные сохраняются в localStorage. В README описал запуск, а в REPORT.md показал пример добавления и выполнения задачи со скриншотами. Основные сценарии проверены на опубликованном сайте.
